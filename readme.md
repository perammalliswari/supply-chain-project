# Healthcare Analytics Dashboard

## 📌 Project Overview

An interactive **Healthcare Analytics Dashboard** built using **Power BI and Excel** to analyze patient admissions, treatment costs, length of stay, readmissions, and doctor performance.

The project transforms healthcare data into meaningful KPIs and visual insights to help understand hospital performance, patient trends, and healthcare costs.

## 🎯 Project Objectives

- Analyze patient admission trends.
- Monitor total patients and billing amounts.
- Calculate and analyze average length of stay.
- Identify patient readmissions.
- Analyze doctor-wise patient load.
- Compare medical conditions and treatment costs.
- Analyze insurance provider revenue.
- Identify trends that can support better healthcare decision-making.

## 🛠️ Tools & Technologies

- **Power BI**
- **DAX**
- **Microsoft Excel**
- Data Cleaning
- Data Modeling
- Star Schema
- Data Visualization

## 📊 Data Model

The project uses a structured **Fact and Dimension data model**.

### Fact Table
Contains the main healthcare transaction/admission information used for analysis.

### Dimension Tables
Includes supporting information such as:

- Patient
- Admission
- Discharge
- Doctor
- Other healthcare-related attributes

The model allows the dashboard to analyze healthcare metrics across different dimensions.

- Doctor-wise Patient Count

### Page 2 — Patient & Doctor Analysis

## 🔍 Key Analysis

The dashboard helps answer questions such as:

- Which medical conditions have the highest treatment costs?
- Which months have the highest number of admissions?
- Which doctors handle the highest patient load?
- Which departments have higher readmission levels?
- Which insurance providers contribute the most revenue?
- What is the average patient length of stay?

Users can filter the dashboard based on:

- Gender
- Admission Type
- Insurance Provider
- Medical Condition
- Doctor

## 💡 Business Value

The dashboard provides a simple way for healthcare stakeholders to monitor patient activity, costs, and operational performance. The insights can support decisions related to resource planning, patient care, readmission monitoring, and cost management.
